## 0. 数学长什么样

```
I   数系与运算 ──┐
II  代数 ────────┤
III 几何 ────────┼──→ V 分析 ──→ VII 概率统计
IV  三角 ────────┘         ↑
VI  线性代数 ──────────────┘（多元分析、统计都要它）
VIII 逻辑与证明：贯穿，不单独成关，最后收口
```

依赖是硬的：V 要 I+II，VI 要 II，VII 要 II+V（三），VIII 什么时候较真什么时候补。

## I. 数系与运算

自然数 → 整数 → 有理数 → 实数 → 复数（先到实数，复数后置）。核心：运算律、分数、指数、对数、绝对值、不等式。

- 前置：无。
- 过关：分数与指数运算不出错；`log` 知道是指数的逆；不等式变号不犯错。
- 位置：✅ 基本可用，短板只剩符号熟练度。

## II. 代数

核心：把未知数当对象，用恒等变形解约束。

1. 整式、分式、因式分解
2. 一元一次/二次方程，不等式
3. 函数语言：定义域、对应、图像、单调、奇偶（V 的门票）
4. 二元方程组：消元、交点、无解/无穷解
5. 三元消元：相加保解
6. 多项式余式、复数入门（后置）

- 过关：三元能独立消元并说清"左边加左边、右边加右边，解不丢"；二次方程判别式与图像对应上。
- 位置：✅ 1–5 已过（2026-09-11：`x=1,y=2,z=3` 独立解出；二元秒解并说清平行/重合）。

## III. 几何

欧氏几何 → 相似与比例 → 圆 → 解析几何（坐标＋方程）→ 立体入门。

- 前置：I。
- 过关：相似能算够不着的距离；圆面积能用极限切出来（做过 `πr²`）；直线/圆方程与图像互译。
- 位置：🔵 半过。圆面积用极限切过；相似、解析几何没系统走。是欠账，要补。

## IV. 三角

角度 → 弧度 → 单位圆 → sin/cos/tan → 恒等式 → 波与周期。

- 前置：III（相似＋圆）。
- 过关：单位圆上读出任意角 sin/cos 并说清"投影"；解释周期 `2π` 从哪来；证出 `sin²+cos²=1`。
- 位置：⬜ 未开始。V 后半段和信号的门票，别拖太久。

## V. 分析（函数 → 极限 → 微分 → 积分 → 级数 → 方程 → 多元）

数学的主干，也是走得最远的一支。

- V1 函数与图像 ✅：比例、一次、二次、指数对数，能画形说快慢拐点。
- V2 极限 ✅：亲手做过 `((4+h)²-4²)/h=8+h → 8`。
- V3 微分 ✅：多项式秒求导；`导数=0` 只是候选，变号才是极值（`t³` 在 0 处平一下不是极值）；围栏约束优化独立走完 `50m²`。
- V4 积分 ✅（2026-09-11）：`S(3)=9` 总量与 `v(3)=6` 速度分清；`S(T)=T² → S'=2T=v(T)` 自己写出；8 矩形估算知高估低估。
- V5 级数与逼近 ✅（2026-09-18）：能把 `e^x` 写成那串块并说清**为什么**（`e^x` 求导等于自己＋`e^0=1` ⇒ 每块求导回退一格 ⇒ 分母必须是阶乘）；`e^0.1` 实测误差随块数掉一个数量级。
- V6 微分方程 ✅（2026-09-18）：已知变化规律反推函数。规则 `y'=k·y` ＋起步 `y(0)=C₀` → `y=C₀·e^{kx}`；增长与衰减同一条公式（`k` 取负即衰减，半衰期 `=ln2/|k|`）；能分清"连续"与"分期"。
- V7 多元与向量微积分 ⬜：梯度、偏导。VI3 之后才来，不到不碰。

## VI. 线性代数（方程组 → 向量空间 → 矩阵 → 特征值）

- VI1 方程组与行列式 ✅（2026-09-11）：消元＋三种解的几何；`2×2` 行列式＝两边张成的平行四边形面积（`3×2-0×1=6`，`4×3-0×2=12`），顶点是原点、`u` 尖、`v` 尖、`u+v` 尖。
- VI2 向量与空间 ✅（2026-09-18）：线性相关、张成、基、坐标与换基。能判相关并说出为什么（`u=(2,0)、v=(0,3)` 够用且无关，`w=(1,1)` 多余因 `3u+2v=6w`）；能讲清同一向量两套坐标怎么换（斜基列方程 `a+b=5、a-b=1`，各占一根轴的基直接除）。
- VI3 矩阵＝变换 ⬜：矩阵是动作不是表格；乘法＝复合所以不可交换；行列式为 0＝压扁＝不可逆。
- VI4 特征值 ⬜：方向不变只拉伸的方向。判据：`2×2` 手算特征值并在图上指出拉伸几倍。
- VI5 二次型与最优 ⬜：最小二乘＝投影，正定＝碗形。线代与分析、统计的接缝。

## VII. 概率与统计

计数与概率 → 随机变量与分布 → 期望方差 → 大数定律与中心极限 → 统计推断 → 回归与随机过程。

- 前置：II + V4（连续分布要用积分）。
- 位置：⬜ 未开始，前置已够，但按顺序先走 VI3、VI4。

## VIII. 逻辑与证明

集合、命题、量词、直接/反证/归纳、实分析（深水区）。

- 不单独排队，碰到"凭什么"就补一块。实分析只在你追问"什么条件下才成立"时开。
- 位置：会因果推理、用过极限，没学量词与写法。

## 学习记录

### 第一次学习：从面积与斜率到优化（2026-08-05）

**速度—时间图的面积＝路程**
- 匀速：矩形面积＝路程。匀加速：三角形 $\frac12\times3\times4=6$ 米。梯形：$\frac{2+6}{2}\times4=16$ 米，自己发现＝平均速度 $4\times4$。
- 曲线下面积：切得越细，"锯齿"越贴曲线，估算越准。

**路程—时间图的斜率＝速度**
- 每秒增 3 米 ⇒ $3\text{ m/s}$。
- 辨析：斜率取决于路程变化量与时间变化量之比，与图像是否过原点无关；斜率保留正负号，速度大小才是其绝对值；累计路程图不下降，斜率通常非负。

**从平均斜率到瞬时斜率（极限）**
- 待巩固：要分位置值 $s(t)$ 与速度（位置对时间的变化率）；平均速度 $=\frac{s(b)-s(a)}{b-a}$，不是两个位置值的平均。
- 取 $(4,4^2)$ 与 $(4+h,(4+h)^2)$：$\frac{(4+h)^2-4^2}{h}=8+h$，令 $h\to0$ 得瞬时斜率 8；推广到 $\frac{d}{dt}(t^2)=2t$，$t=5$ 时瞬时速度 10。求导＝求切线斜率。

**极值——导数为 0 只是候选**
- $y=t^2$ 在 $t=0$ 是全局最小（左负右正）；$y=-t^2$ 相反（左正右负，最高点）。必须看导数变号。
- 求导规则：$\frac{d}{dt}(4t^2-3t+7)=8t-3$；系数要保留并乘指数——$(4t^2)'=4\cdot2t=8t$，$(2t^3+4t^2-1)'=6t^2+8t$。
- 极值流程：$f(t)=t^2+6t+5$ → $t=-3$、值 $-4$，最低点 $(-3,-4)$；$g(t)=-t^2+6t+1$ → 最高点 $(3,10)$。

**约束优化——围栏问题（A3 通关证据）**
- $2x+y=20$ → $y=20-2x$、$A(x)=20x-2x^2$、$A'(x)=20-4x$ → $x=5$、$y=10$，最大 $50\text{ m}^2$。流程：约束 → 单变量函数 → 求导 → 极值 → 回实际量。
- 辨析：不是找导数的最大值，是用导数判断原函数的极值（最大点处导数为 0 且由正变负）。

**推开积分的门**
- $s(t)=t^2$ 在 $[2,3]$ 平均速度 5，而 $s'(2)=4$。曲线速度图下面积＝总路程，不能用首末速度平均：$\int_0^2 t^2\,dt=\frac83$。
- 右端点 4 矩形：$0.5(0.25+1+2.25+4)=3.75$（递增且宽 ⇒ 明显高估）；切到 8、16 份：3.1875、2.921875，逼近 $\frac83$。
- 模糊：还没直观理解"累积面积函数的导数为什么等于当前速度"，暂不认作已掌握。教学调整：先回 $v(t)=2t$ 三角形。

### 第二次学习：复攻"累积函数的导数"（2026-09-10）

- 自己算出 $v(t)=2t$ 从 0 到 T 的累积路程 $S(T)=\frac{T\cdot v(T)}{2}=T^2$，并纠正"v-t 图是曲线"——是直线。
- 认出 $S(T)=T^2$ 就是玩过的 $y=t^2$：T=1、2、3 分别走 1、4、9 米。
- 混淆：把 $S(3)$ 写成 6，而 6 其实是 $v(3)$——"到 T 为止攒下的总量"和"T 这一瞬的速度"写成了同一个东西，正是本关要区分的两个人。
- 待打通："斜率"只被理解为两点连线的平均斜率，还没把"某一点的斜率"当成随 T 变化的表达式，所以 $S$ 的斜率等于 $v$ 这步仍未自己走出。
- 下一步：把 $S=T^2$ 在任意 T 的斜率写成 $2T$，与 $v(T)=2T$ 并排对照；若仍未通，按止损规则换线走 B1（线性方程组）。
- 状态：A 线第 4 站（积分）进行中，未过关。

### 第五次学习：VI2 半程 + V5 开局、e 补课（2026-09-14）

- VI2 向量：`u=(3,0)、v=(0,2)` 下 `p=(6,4)=2u+2v` 独立凑出；`u,v` 互相凑不出 ⇒ 无关；任意点 `(a,b)=(a/3)u+(b/2)v`，坐标 `(a/3,b/2)`。对角换基：乘回去 `(2·3,2·2)=(6,4)`，除回去 `(6/3,4/2)=(2,2)`。
- 斜基：`u=(1,1)、v=(1,-1)`，点 `(4,2)` 初答 `4u+2v`（验算得 `(6,2)`，纠正），列 `a+b=4、a-b=2` 解出 `3u+1v`：斜基坐标要解方程组（VI1 消元的用处）。
- 相关：`u=(1,1)、v=(2,2)` 答出相关（`v=2u`）；`a·u+b·v=(a+2b,a+2b)` 只能凑 `y=x`，`(4,3)` 凑不出——相关不能当基。

- 三行：① 懂了凑、相关＝多余、两套坐标、斜基要解方程、e 的来历与三步数；② 模糊：弯＝斜率变多快、二阶导与弯的关系；③ 下次从 `y=x`（斜率恒 1、不弯）vs `y=x²`（斜率 0,2,4、往上弯）对照继续，不开 `x³/6` 新公式。

### 第六次学习：V5 级数通关 + VI2 收口 + V6 微分方程（2026-09-18，一题一问）

- 重走 `e^0.1` 三步估值：起点 `1` → 加 `x` 对斜率 → 加 `x²/2` 对弯；node 实测累加 1.1051709181，与真值一致。
- **分母来历打通**：`xⁿ` 一路求导到底剩下的常数就是 `n!`（实测 `x²`→2、`x³`→6、`x⁴`→24）；自己算出 `x⁵` 那块的分母是 `120 = 5!`。
- **为什么求导能回退一格**：`x⁵/120` 求导得 `5x⁴/120`，指数 5 掉下来当系数，分母 120 里藏着 `5×24` 正好吃掉 → `x⁴/24`；他自己说出"指数下来被分母抵消了"。分母＝阶乘不是巧合，是为回退配的。
- **为什么这串就等于 `e^x`**：`e^x` 的独门性质是"导数等于自己"且 `e^0=1`；逐块求导各往前挪一格，整串求导后仍是自己——实测 x=0/0.1/0.5 处差 1e-11 级；截断时差值正好等于被砍掉的尾块（`3^10/10! = 0.01627232`，对上实测差 1.63e-2）。
- **块号与指数**：第 n 块 `= x^(n-1)/(n-1)!`（指数比块号小 1，因为第 1 块必须是常数当底座）。先把 `x⁸/8!` 错记成第 8 块，纠正后自己答对"`x¹⁰/10!` 是第 11 块"。
- 三行：① 懂了那串块为什么是 `e^x`（求导等于自己＋0 处为 1）、分母阶乘的来历；② 模糊：`e^2` 的复利含义没答，留作下次开口第一问；③ 下次从 VI2 收口继续，再走 V6。
- 补问已答：`e^2 = 7.38905610` 在复利故事里＝"1 块钱、连续复利、放 2 年"，一次答对；顺带打通来路——连续复利下"每秒新增的钱＝当前手里钱的 100%"，所以增长速度＝当前数额，这就是 `(e^x)'=e^x` 的出处（V6 `y'=y` 的伏笔）。
- **V5 判定：通关**（能讲清"为什么是这串块"，且知道误差随块数可控）。

**VI2 收口（同日继续）**

- 判基：`u=(2,0)、v=(0,3)、w=(1,1)` 能不能当基——自答"不行，`3u+2v=6w`"（实算吻合，即 `w=½u+⅓v`）；补上更狠的一句：平面里最多只有两个无关向量，第三个必然多余。
- 换基两方向：斜基下 `(5,1)` 自答 `(3,2)`（`3u+2v=(5,1)`），会列 `a+b=5、a-b=1`；对角基 `u=(2,0)、v=(0,3)` 下 `(10,6)` 自答 `(5,2)`，`u=(3,0)、v=(0,5)` 下 `(12,20)` 自答 `(4,4)`。
- **为什么对角基能省掉解方程**：先答"省下来了列方程的"（现象层），提示后说清实质——两个基向量各占一根轴（一个的 y 分量为 0、另一个的 x 分量为 0），x 只由 `u` 出、y 只由 `v` 出，所以只需除法；斜基每个向量在两根轴上都掺和，必须联立。
- 纠正记录：他先给的理由是"因为不是斜基"（现象层），已拧到"各占一根轴"（机制层）；另修正我之前"分量里有 0 就行"的松说法——必须是**各占一根轴**，否则 `u=(2,0)、v=(1,3)` 仍要两步代入。
- **VI2 判定：收口通关。**

**V6 微分方程（同日继续）**

- 三例实测：`5e^x` 满足 `y'=y`（常数系数原样留；复利版＝本金 5 元，每秒仍涨当前量的 100%，递推比值恒 5.000000）；`e^x+3` 不满足（那 3 是死钱，常数的导数为 0）；`e^{2x}` 不满足 `y'=y`（导数是自己的 2 倍）。
- 解族与初值：`y'=y` 的解是一整族 `C·e^x`，`C` 由起步值锁死（起步 3 元 → `y(0)=3`、`C=3`）。
- **通用公式**：`y'=k·y`、`y(0)=C₀` → `y = C₀·e^{kx}`。自己填对 `y'=3y`、起步 2 → `y=2e^{3x}`（实测递推 40.16927 vs `2e³=40.17107`；求导 120.51322 `=3·2e³`）。
- 衰减：`y'=-y`、起步 1 → `y=e^{-x}`；现象＝放射性/电容放电/牛顿冷却；半衰期 `= ln2/衰减率`（实测 `e^{-0.69315}=0.5`）。自答 `C₀·e^{-kx}`，已拧回"就是通用公式里 `k` 取负，不是第二套公式"。
- **连续 vs 离散**（他自己问"一年衰减 10%？"）：`y'=-0.1y` 是"每瞬时的减少率＝当前量的 10%"——连续 10 年 `100e^{-1}=36.7879`；"每年到期固定减 10%" `100×0.9^{10}=34.8678`；连续版一年实际掉 9.52%（`e^{-0.1}=0.904837`）。和 e 的复利来历是同一条缝。
- **V6 判定：通关**（能从"规则＋起步值"反推函数，增长/衰减都行，并分得清连续与分期）。
